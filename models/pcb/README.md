# โมเดล PCB สำหรับแอป

โฟลเดอร์นี้ยังไม่มีน้ำหนักโมเดลที่ฝึกแล้ว จัดเตรียม `best.pt` และ `metadata.json` ด้วย `python -m scripts.export_model` หลังฝึกและตรวจผลเสร็จ โดยสคริปต์จะตรวจชื่อคลาสและสร้าง SHA-256 ให้

ระหว่างรอโมเดล ใช้ `python main.py --mock` เพื่อทดสอบหน้าจอ ผลจำลองไม่บันทึกภาพหรือประวัติจริง
