# ผลตรวจต้นแบบ PCB วันที่ 15 ตุลาคม 2026

## ขอบเขตที่ตรวจ

ตรวจการทำงานซอฟต์แวร์และโค้ดเตรียมฝึกบน Windows, Python 3.10.8, PyQt6 6.11.0, Pillow 12.3.0, Ultralytics 8.4.155, PyTorch 2.14.0+cpu และ torchvision 0.29.0+cpu ไม่มี CUDA ใน environment ที่ตรวจ

**ยังไม่ได้เริ่มเทรนโมเดล** และยังไม่มีค่า Precision/Recall/mAP ของโมเดล PCB ที่ฝึกแล้ว

## ผลตรวจซอฟต์แวร์

- `python -m unittest discover -s tests -v`: ผ่าน 35 กรณี รวม pipeline, SQLite, UI, adapter ของ Ultralytics, TensorBoard และการเก็บ/กู้ checkpoint
- `python -m compileall -q app scripts main.py`: ผ่านในระหว่างพัฒนา
- `python -m pip check`: ไม่พบ dependency ที่ขัดกัน
- ตรวจภาพหน้าจอ Qt offscreen และแก้การโหลดฟอนต์ภาษาไทยให้แสดงผลได้
- คำสั่ง `python -m scripts.train` ทำ dry run สำเร็จ ค่า `training_started` เป็น `false`
- คำสั่ง evaluate แบบไม่ใส่ `--execute` แสดงแผนโดยไม่ประเมินโมเดล
- TensorBoard 2.21.0: ทดสอบเขียนและอ่าน event log แยกสอง run ด้วยค่า epoch จำลอง พบ Loss, mAP และ Learning Rate ตามค่าที่ส่ง รวมทั้งทดสอบปิดและเปิด callback ใหม่ และตรวจคำสั่งเปิดโปรแกรมได้ โดยไม่เริ่มเทรน
- Colab runner: จำลองการถูกขัดจังหวะ การเขียน snapshot ล้มเหลว checkpoint เสีย การเปลี่ยนชุดข้อมูล และการเทรนจบแล้ว ตรวจเลือก checkpoint และค่า resume ได้โดยไม่ฝึกจริง พร้อมตรวจ syntax ของ code cell ใน Notebook แล้ว ยังไม่ได้รันบน GPU/Google Drive ของ Colab จริง

กรณี UI ใช้ผลจำลองที่กำหนดแน่นอน รวมทั้ง fixture ที่เปิดการบันทึกเพื่อทดสอบระบบจริงส่วนไฟล์/ฐานข้อมูล ส่วน adapter สร้าง YOLO11 น้ำหนักสุ่มชั่วคราวแล้วรัน inference กับภาพสังเคราะห์โดยไม่เรียก train จึงตรวจ API ได้แต่ไม่เป็นผลทดลองคุณภาพของโมเดล

## ผลตรวจชุดข้อมูล

| ชุด | ภาพ | ป้ายกำกับ | Label ว่าง |
|---|---:|---:|---:|
| train | 5,810 | 5,810 | 1,758 |
| valid | 556 | 556 | 184 |
| test | 276 | 276 | 90 |
| รวม | 6,642 | 6,642 | 2,032 |

ตรวจ decode ภาพทั้งหมดและรูปแบบป้ายกำกับ ไม่พบไฟล์ภาพอ่านไม่ได้ label หาย class ID นอกขอบเขต หรือกรอบ normalized ผิดเงื่อนไข พบภาพเหมือนกันตาม SHA-256 ข้าม split 39 กลุ่ม รวม 878 ไฟล์ และจำนวนภาพต่างจากยอด 6,652 ในรายงาน 10 ภาพ ดูรายการเต็มใน [dataset_audit.json](dataset_audit.json)

Manifest SHA-256 ของชุดข้อมูลที่ตรวจ:

```text
1fd3df4454877b3253a05f8295e9d3c4bd3e08433b8479522067ec01041c7c97
```

การตรวจนี้ไม่ยืนยันคุณภาพ annotation ด้วยสายตาทุกภาพ ไม่ตรวจภาพคล้ายกันด้วย perceptual hash และไม่ยืนยันว่าภาพของ PCB ชิ้นเดียวกันแยกอยู่ใน split เดียวกันทั้งหมด

## งานที่เตรียมไว้สำหรับภายหลัง

ทบทวนภาพซ้ำและแหล่งข้อมูล เตรียม pretrained YOLO11 ปรับ configuration ตามเครื่อง จากนั้นจึงสั่งฝึก/ประเมิน/ส่งออกโมเดลด้วยคำสั่งใน README ตามลำดับ ไม่มีเงื่อนไขคะแนนขั้นต่ำสำหรับงานเรียนรู้นี้
